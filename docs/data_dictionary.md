# Data Dictionary

The project dataset contains 1,500 synthetic employee records and 15 fields.

| Column | Description | Expected type |
|---|---|---|
| `EmployeeID` | Employee identifier; expected unique | Text |
| `Age` | Employee age in years | Integer |
| `Department` | Department name | Text |
| `JobRole` | Job role | Text |
| `EducationLevel` | Education category | Text |
| `EmploymentType` | Employment category, such as Contract or Full-time | Text |
| `MonthlySalaryINR` | Monthly salary in Indian rupees | Integer/numeric |
| `YearsAtCompany` | Years employed at the company | Integer |
| `YearsInCurrentRole` | Years in current role | Integer |
| `Overtime` | Overtime indicator | Text: Yes/No |
| `JobSatisfaction` | Recorded job satisfaction level | Integer |
| `PerformanceRating` | Recorded performance rating | Integer |
| `CommuteDistanceKM` | Commute distance in kilometers | Integer |
| `TrainingSessionsLastYear` | Training sessions attended last year | Integer |
| `Attrition` | Whether the employee left | Text: Yes/No |
