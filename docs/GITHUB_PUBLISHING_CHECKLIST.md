# GitHub Publishing Checklist

- [ ] Confirm the dataset is synthetic and contains no real personal data.
- [ ] Put the CSV in `data/raw/` only if you are allowed to redistribute it.
- [ ] Add Google Sheets dashboard link in `google-sheets/README.md`.
- [ ] Add dashboard screenshot to `docs/screenshots/hr-dashboard.png`.
- [ ] Review SQL table and column names against the imported schema.
- [ ] Remove any local file paths, credentials, tokens, or private links.
- [ ] Add a license if you want to specify reuse terms.
- [ ] Check the rendered README on GitHub after pushing.
